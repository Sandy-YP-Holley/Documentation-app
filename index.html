Introduction

Python is a high-level, interpreted programming language known for its ease of use and readability. It emphasizes code readability with its notable use of significant whitespace.

Its language core and libraries provide tools suited for many tasks, including web development, data analysis, machine learning, and automation.

Hello World

To get started with Python, the traditional first step is to print a "Hello, World!" message to the console. This verifies that your environment is correctly set up.

In Python, this requires just a single line of code, utilizing the built-in print function:

print("Hello, World!")
Variables and Types

Python is dynamically typed, meaning you do not need to explicitly declare data types when creating variables. The interpreter infers the type automatically at runtime.

x = 5 name = "Alice"

Here are some of the most common standard data types built into Python:

  • Int: Integer numbers (e.g., 5, -3)
  • Float: Floating-point numbers (e.g., 3.14, -0.5)
  • Str: Strings of characters (e.g., "Hello")
  • Bool: Boolean values (True or False)
  • List: Ordered mutable sequences
Control Flow

Python uses standard conditional statements like if, elif, and else to control the flow of execution based on specific evaluations.

Unlike languages that use curly braces, Python relies heavily on indentation to define code blocks:

if x > 0:
    print("Positive")
else:
    print("Zero or Negative")
Functions

Functions help break our code into smaller, reusable pieces. They block out logic that only runs when explicitly invoked.

In Python, functions are defined using the def keyword followed by the function name and parentheses:

def greet(user):
    return "Hello, " + user
